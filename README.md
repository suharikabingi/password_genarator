# 🔐 Password Generator

A simple, secure, and responsive **Password Generator** web application built using **HTML, CSS, and JavaScript**. This project helps users generate strong, random, and customizable passwords to improve online security and protect their accounts.

---

## 📌 Project Overview

Weak passwords are one of the main reasons for security breaches. This Password Generator allows users to create highly secure passwords by selecting different password criteria such as length, uppercase letters, lowercase letters, numbers, and special characters.

The application features a clean, interactive, and responsive interface, making it easy to use on both desktop and mobile devices.

---

## ✨ Features

- 🔒 Generate strong and secure passwords
- 📏 Customize password length
- 🔠 Include uppercase letters (A–Z)
- 🔡 Include lowercase letters (a–z)
- 🔢 Include numbers (0–9)
- 🔣 Include special characters (!, @, #, $, etc.)
- 📋 Copy generated password to clipboard
- 📱 Fully responsive design
- ⚡ Fast and user-friendly interface
