# Password Generator

Simple offline password generator built with HTML/CSS/JS.

Usage

- Open `index.html` in a browser.
- Choose length and character types.
- Click `Generate` to create a password.
- Click `Copy` to copy it to clipboard.

Notes

- This is an offline, client-side tool. Do not use it for high-security needs without reviewing the code.
- Replace `images/logo.png` with your own logo image if desired.
